# HARF · حرف

Tienda online de camisetas con caligrafía árabe — https://zaid5195.github.io/harf/

- `index.html`, `legal.html`, `style.css`, `products.js` — la web (GitHub Pages, rama `main`).
- `designs/` — diseños para imprimir (PNG transparentes), subidos a Printify.
- `social/` — posts de Instagram y textos (`captions.md`).
- `tools/` — scripts que generan los diseños y los posts (Playwright + fuentes OFL).

Productos impresos bajo pedido por Printify (Textildruck Europa). Pagos con Stripe Payment Links.
